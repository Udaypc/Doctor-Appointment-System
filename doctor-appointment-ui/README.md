# Doctor Appointment UI

Next.js (React + TypeScript) frontend for the Doctor Appointment System.

## Run

Start Eureka, the Spring Boot services, and the API Gateway first (see the [root README](../README.md)). Then:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

`/api/*` is rewritten to the API Gateway at `http://localhost:9091`.
